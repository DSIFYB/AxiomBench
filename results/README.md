# Результаты

Реальных результатов моделей пока нет. Unit tests и ответы mock server проверяют инфраструктуру и не считаются AI benchmark результатами.

Сохранять пары `model-run.jsonl` + `model-run.jsonl.meta.json` и итоговый report. В этой папке локальные прогоны исключены из git. Для будущего публичного leaderboard добавлять отдельно отобранные результаты с разрешёнными логами, model revision, quantization, hardware, suite hash, budgets, количеством пропусков и протоколом проверки.

Без ответов/версий/протокола не добавлять опубликованные проценты из рекламных таблиц. Не сравнивать полный чужой benchmark с нашим subset и не объединять разные версии набора в одну строку.
